# WADOUD.DENTAL — دليل أول 30 يوم لمساعد الأسنان

صفحة هبوط عربية باتجاه RTL، متجاوبة مع الهاتف والحاسوب، للتعريف بالدليل الرقمي:
**«دليلك لأول 30 يوم لمساعد الأسنان الجديد في العيادة»**.

## محتوى المشروع
- صفحة تعريفية تسويقية باللغة العربية.
- عرض مراحل الأيام الثلاثين ومحتويات الدليل.
- أسئلة شائعة وتنبيه واضح إلى أن المحتوى توجيهي عام ولا يحل محل إشراف طبيب الأسنان أو بروتوكولات العيادة.
- أزرار الشراء تشير إلى متجر Etakka: https://wadoudpasha.etakka.com/
- ألوان الهوية: كحلي داكن، بيج دافئ، ذهبي هادئ، وعاجي.

## تفعيل النشر لأول مرة
ملفات الموقع تُجهّز تلقائيًا بواسطة GitHub Actions في:
`.github/workflows/deploy-site.yml`

لتفعيل الاستضافة:
1. افتح **Settings → Pages** في هذا المستودع.
2. ضمن **Build and deployment** اختر **GitHub Actions** مصدرًا للنشر.
3. انتقل إلى **Actions** ثم شغّل سير العمل **Deploy WADOUD dental guide landing page** أو أعد تشغيل آخر محاولة.

بعد نجاح سير العمل سيظهر رابط الموقع في نتيجة النشر ضمن Actions.

## ملاحظة حول معاينات الموقع
الصور الموجودة في قسم المعاينة رسومات توضيحية لأقسام الدليل، وليست صورًا حرفية من صفحات ملف PDF.

## قبل الإطلاق التجاري
يرجى توحيد عنوان الغلاف داخل ملف PDF مع عنوان صفحة البيع، وتصحيح اسم المُعدّ في النبذة من «وضوض» إلى «ودود». راجع أيضًا النسخة النهائية من الدليل وتأكد من توافقها مع إجراءات العيادة المحلية وإشراف طبيب الأسنان.
